# Archive

This directory holds historical status, planning, and validation documents
that were previously at the repository root. They are kept for history and
git blame continuity only — **none of them describe the current state of
the repository.** Several make claims (test counts, onboarding flows,
deployment status) that are no longer accurate.

Each file carries a banner at the top pointing to whichever current doc
superseded it. In general:

- For MVP status, validation results, and phase/week progress reports, the
  current source of truth is [`README.md`](../../README.md) at the
  repository root.
- For deployment procedure and infrastructure, the current source of truth
  is [`deploy/aws/README.md`](../../deploy/aws/README.md).
- For module-level architecture and service inventory, see
  [`docs/MARKETOS_MODULAR_ARCHITECTURE.md`](../MARKETOS_MODULAR_ARCHITECTURE.md)
  and [`docs/SERVICE_MODULES.md`](../SERVICE_MODULES.md).

Do not cite anything in this directory as a current claim about the
system. If you need the historical context these docs recorded, read them
here; if you need to know what's true today, use the docs linked above.
