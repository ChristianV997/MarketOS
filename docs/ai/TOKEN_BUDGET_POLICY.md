# Token Budget Policy

Updated: 2026-07-31

- Retrieve target symbols and direct references before whole files.
- Use `docs/ai` before broad searches.
- Use one context/navigation mechanism per question.
- Use architecture indexing only for architecture or large-refactor work.
- Filter test and static-analysis output to actionable deltas.
- Review another agent’s work from the diff, affected symbols, tests, and architecture impact.
- Before reading more than 20 symbols, summarize why more context is necessary.
- End substantial sessions with a compact handoff.
